# Pin Token

**Pin Token** is an open-source Web3 and blockchain application. The code is written mainly in the stack already in this repository and maintained by [Banny Sukumar](https://github.com/Bannysukumar), a blockchain and full-stack developer.

This repository is public so developers can read the source, reuse it under the MIT License, and send improvements.

## About this project

Pin Token lives at [`github.com/Bannysukumar/pin-token`](https://github.com/Bannysukumar/pin-token). Use it as a starting point for a Web3 and blockchain application, or study how the the stack already in this repository parts fit together.

## Getting started

```bash
git clone https://github.com/Bannysukumar/pin-token.git
cd pin-token
```

Open the project in your editor. Install dependencies only if this repo already includes a manifest such as `package.json`, `requirements.txt`, or a `.csproj` file.
